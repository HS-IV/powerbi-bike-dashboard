# powerbi-bike-dashboard
# 🚲 Power BI Dashboard – CycleHause Bike Shop

This is a real-world analytics project built in **Power BI**, using SQL Server and CSV data sources.  
It addresses a request from CycleHause Bike Shop to deliver a data-driven dashboard showing key performance metrics and pricing strategy insights.  
The final result includes a multi-page report, pricing recommendations, and a full video walkthrough of the finished dashboard.

---

## 🧾 Project Objectives

CycleHause Bike Shop requested a dashboard that:

- Displays **hourly revenue** patterns across the week
- Shows **profit and revenue trends** over multiple years
- Breaks down **seasonal revenue** performance
- Analyzes **rider demographics** (e.g., casual vs registered)
- Includes a **recommendation page** for pricing strategy based on historical data
- Uses clean visuals and company colors
- Is easy to navigate and insightful for business decision-making

## 🔧 Tools Used

- Power BI Desktop
- SQL Server Express + Management Studio
- AWS EC2 (Windows-based VM)
- DAX & T-SQL for KPIs and modeling
- CSV files as source data

---

## 📈 Key Features of the Dashboard

- KPIs: Total Riders, Revenue, Profit, and Profit Margin
- Card visuals with icons for quick insights
- Seasonal and hourly trends (via line + column visuals)
- Rider Demographics pie chart
- Recommendation page for pricing (based on analysis)
- Professional formatting and layout
